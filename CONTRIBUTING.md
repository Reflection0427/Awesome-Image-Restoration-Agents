# Contributing

Contributions are welcome through issues and pull requests.

For a new paper, verify that it makes a material contribution to agentic image restoration, is not a duplicate, and has stable publication metadata. The method must include autonomous restoration decisions, learned or explicit planning, tool invocation, feedback, reflection, memory, or another genuine agent loop. Every formal entry must include one original author-created Figure cropped from a pinned official PDF. See [the paper tracker guide](docs/PAPER_TRACKER.md) for the required metadata and review commands.

Automated candidate pull requests are queues for human review, not additions to the formal collection. Do not merge their candidates directly into README.
